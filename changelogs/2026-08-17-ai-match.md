# 2026-08-17：自动消息 AI 匹配

## 新增功能

- 自动消息配置新增可折叠的“AI匹配”区域，支持 DeepSeek API Key、我的简历、期待岗位、补充要求和提示词预览。
- “DeepSeek API Key”标签可直接打开 DeepSeek 平台。
- AI 匹配在普通岗位条件、关键词过滤和重复沟通检查全部通过后执行，是发送前的最后一道筛选。
- BOSS直聘和猎聘均支持 AI 匹配；未匹配岗位会跳过，不会发送消息。
- DeepSeek 请求由扩展后台直接发起，API Key 不会下发给招聘网站内容脚本。

## 结果与调试

- 启用 AI 匹配后，已发送信息列表最右侧显示本次任务的 AI 匹配结果；该结果不写入正式岗位记录、沟通历史或导出数据。
- 自动消息调试日志增加 DeepSeek 请求体、响应体和请求异常记录。
- API Key 与 Authorization Token 始终不会写入日志。

## 交互与样式

- AI 匹配配置项增加 hover 提示。
- 优化提示框的显示与定位，鼠标移开后即时消失。
- 推荐岗位筛选和 AI 匹配使用统一尺寸、样式和居中的 SVG 展开箭头。
- AI 匹配结果改为复用已发送公司信息的深色悬浮信息卡，不再使用有延迟的浏览器原生提示。
- 已发送信息列表使用固定列轨道，确保公司、岗位、薪资和 AI 匹配结果跨行对齐。
